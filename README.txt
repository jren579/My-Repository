TRAINING CHART - standalone app

Put it online once (free, about 5 minutes):
1. Sign in at github.com and create a new PUBLIC repository, e.g. "training-chart".
2. On the repository page choose "uploading an existing file" and upload every file
   in this folder (index.html, sw.js, fflate.js, manifest.webmanifest, the three icons).
3. Settings > Pages > Source: "Deploy from a branch", branch "main", folder "/ (root)". Save.
4. After a minute your address appears there: https://YOURNAME.github.io/training-chart/

Install on your iPhone:
1. Open that address in Safari.
2. Share > Add to Home Screen.
3. Open it from the icon once while online. After that it works without signal.

Your data lives only on the phone. Use Setup > Download backup now and then.
The repository holds only the app, never your entries.
